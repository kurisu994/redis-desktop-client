## 已解阻碍

- ✅ **MONITOR 任务泄漏与竞态**：后台异步任务未清理 + 事件监听竞态，v0.2.3 修复（句柄管理 + 取消信号）。
- ✅ **Hex 模式数据丢失**：Monaco Editor 条件渲染共享同一 model，v0.2.1 通过为 Hex 视图和主编辑器分配不同 `path` 隔离。
- ✅ **大字符串渲染卡顿**：v0.2.1 引入 Hex `useMemo` 缓存 + 256KB 截断 + 大值预览/完整加载；Monaco Editor 大值禁用高开销特性。
- ✅ **大数据量表格卡顿**：Hash/List/Set/ZSet/Stream 服务端分页（每页 200 条），List/ZSet 用索引、Hash/Set 用 SCAN 游标、Stream 用 ID 边界。
- ✅ **Key 列表闪烁**：v0.2.4 改为局部更新本地状态，不再触发整库 SCAN。
- ✅ **TTL 倒计时停在 "0s"**：v0.2.3 修复，归零时自动标记 Key 已过期并切换 UI。
- ✅ **重复点击同一 DB 数据消失**：v0.2.3 修复，点击已激活的 db 不做任何操作。
- ✅ **断开连接 Tab 状态残留**：v0.2.3 引入 `closeAllClosableTabs()`，断开时关闭 CLI/Pub/Sub/Monitor Tab，清空 browser 状态，重置各 Store。
- ✅ **监控/PubSub 页面布局未填满宽度**：v0.2.3 修复。
- ✅ **更新弹窗白屏**：v0.2.8 为 `ReleaseNotesMarkdown` 添加错误边界，异常时降级为纯文本。
- ✅ **重试下载进度累计**：v0.2.8 修正，重试时从 0% 重新显示。
